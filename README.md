# IconAnker – öffentlicher Update-Kanal

Dieses Repository enthält ausschließlich öffentliche Updateinformationen und
signierte Installationsdateien für IconAnker. Der Quellcode der Anwendung liegt
nicht in diesem Repository.

## Für Anwender

Die aktuelle Version steht nach der Veröffentlichung als GitHub-Release bereit.
Direkte Updates werden nur akzeptiert, wenn die Downloadadresse HTTPS verwendet,
die veröffentlichte SHA-256-Prüfsumme stimmt und der Installer mit dem erwarteten
IconAnker-Herausgeberzertifikat signiert ist.

## Updateinformation

Die Datei [`update.json`](./update.json) wird erst mit dem ersten signierten
öffentlichen Release bereitgestellt. Sie enthält die Versionsnummer,
Installationsadresse und SHA-256-Prüfsumme der jeweils aktuellen Ausgabe.
